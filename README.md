# GyroAim for PS5

Gyro aiming in any game on a jailbroken PS5.

A resident payload folds the DualSense's gyroscope into the control a game
actually reads, usually the right stick, while a condition you choose is met,
usually holding the left trigger. Tunable from a phone while the game runs.

**Status: planning.** No code yet. See [PLAN.md](PLAN.md) for the architecture,
the hardware-verified baseline it rests on, and the phased build with its
verification gates.

Experimental homebrew for the author's own console. It modifies a running game's
memory: save your progress before testing.
