GyroAim maps the DualSense's gyro onto the sticks, so you can aim or steer by
moving the controller in games that were never built to know it can.

## Added

- **Hold a rotation instead of flowing it.** A rotation can now be read as an
  angle held away from a rest position rather than as a speed, so tilting the
  pad and keeping it there holds the stick over. Meant for steering rather
  than aiming: driving, skating, flying. Set per rotation.
- **Any rotation to any control.** Turning, tilting and leaning each route to
  either stick's horizontal or vertical axis, in either direction, and to more
  than one at once. The view can sit on one stick and movement on the other.
- **A button condition can say which button.** Choosing a button as the
  condition now offers a chip for each one, lights the chips the pad reports
  as held, and will take the whole set from whatever you are holding.
- **Reset to defaults**, on the settings page, back to plain aiming: left
  trigger to switch it on, turning and tilting on the right stick.
- **The panel keeps the service current.** Updating the app used to leave an
  older service running, with nothing saying so. It now replaces a running
  service that differs from the one it carries, and refreshes the boot copy.

## Fixed

- **Settings from one game leaked into the next.** A game's saved profile was
  layered over whatever happened to be live, so anything the profile did not
  name kept the previous game's value, and a game with no profile at all kept
  the previous game's settings and then saved them over the general ones.
  Settings are now rebuilt from the defaults up every time a game starts.
  Profiles saved by earlier versions may already hold values that leaked this
  way; the reset button is the quickest way out.
- **A held angle drifted away over a session.** It was a running total of the
  rotation rate, which creeps without limit. One session left it 147 degrees
  from a full scale of 30: pinned, and deaf to rotation one way. Tilting and
  leaning are now measured against gravity, which is absolute and cannot
  creep. Turning a flat pad is the one case gravity cannot see, and the page
  now says so instead of leaving it a mystery.
- **The resting gyro offset was never learned** when the condition was set to
  Always, because every measurement window was discarded as being in use. That
  left a steady creep in every reading.
- **Large games could not be attached to.** Modules over 48 MB were skipped
  outright, and the search that replaced that limit gave up partway through.
- **The settings page went dead while aiming kept working.** One silent
  browser connection, which phones and speculative connections make
  routinely, stopped the page serving anything at all.
- **A game left half-hooked could not be hooked again.** A leftover gateway in
  an import slot now gets recognised and taken back over.
- **Two copies of the service could run at once**, which could leave a process
  that would not die. Only one runs now, and the panel can tell two builds of
  the same version apart.
- **The routing grid rendered empty** on the settings page.
